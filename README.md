# ORIGINS — Clothing Store Demo

A polished, static ecommerce clothing-store demo for ORIGINS.

## Included
- Responsive storefront and product pages
- Cart, wishlist, search and combined filters
- Demo checkout and customer account
- Product reviews saved locally in the browser
- Size guide plus per-size stock availability
- One-tap WhatsApp support on every storefront page

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

This is a frontend demonstration only: payments, accounts, and inventory are simulated in the browser.
